# ☁️ Cloudflare

> 🇬🇧 [Read in English](./README.md)

**Сложность:** ⭐☆☆☆☆ | **Эффективность:** ⭐⭐⭐⭐⭐

Самый быстрый способ получить базовую защиту. Cloudflare работает как прокси между пользователями и вашим сервером, автоматически фильтруя известных ботов ещё до того, как они достигнут бэкенда.

## Как работает

1. Весь трафик проходит через сеть Cloudflare
2. Cloudflare оценивает каждый запрос (бот-скор от 0 до 100)
3. Вы задаёте правила: блокировать, выдать капчу или пропустить

## Настройка

1. Зарегистрируйтесь на [cloudflare.com](https://cloudflare.com)
2. Добавьте домен и смените NS-записи у регистратора
3. Включите **Bot Fight Mode**: Security → Bots → Bot Fight Mode → ON

## Примеры

- [`worker.js`](./worker.js) — Cloudflare Worker, блокирующий запросы с низким бот-скором

## Плюсы
- Базовая защита без единой строки кода
- Защищает от DDoS, известных плохих IP, брутфорса
- Бесплатного тарифа хватает большинству сайтов

## Минусы
- Трафик идёт через Cloudflare (зависимость от третьей стороны)
- Продвинутые боты умеют имитировать браузер
- Редкие ложные срабатывания на пользователей с VPN
