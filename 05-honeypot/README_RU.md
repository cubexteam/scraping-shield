# 🍯 Honeypot-ловушки

> 🇬🇧 [Read in English](./README.md)

**Сложность:** ⭐⭐☆☆☆ | **Эффективность:** ⭐⭐⭐☆☆

Скрытые поля и ссылки, невидимые людям, но посещаемые ботами. При срабатывании — тихий бан IP.

## Примеры
- [`form.html`](./form.html) — скрытое поле-ловушка в форме
- [`trap.js`](./trap.js) — обработчик ловушки + логика бана IP (Express)

## Плюсы
- Никакого трения для реальных пользователей
- Бот банится молча — не знает, что попался

## Минусы
- Не ловит все боты (некоторые игнорируют скрытые элементы)
- Нужно персистентное хранилище IP (рекомендуется Redis)
