# ⏰ Анализ тайминга запросов

> 🇬🇧 [Read in English](./README.md)

**Сложность:** ⭐⭐⭐☆☆ | **Эффективность:** ⭐⭐⭐⭐☆

Боты делают запросы с идеально равномерными интервалами — люди так не делают.  
Метод отслеживает временные паттерны запросов по IP. Если интервалы слишком "механические" — запрос блокируется.

В отличие от большинства других методов, этот **не зависит от заголовков, репутации IP или JavaScript** — только поведенческий анализ.

## Как работает

1. Сервер записывает временную метку каждого запроса по IP
2. После N запросов вычисляется стандартное отклонение интервалов
3. Очень низкое отклонение = поведение бота → блокировка
4. Высокое отклонение = поведение человека → пропускаем

## Примеры

- [`analyzer.go`](./analyzer.go) — Ядро анализатора тайминга (чистый Go, без зависимостей)
- [`middleware.go`](./middleware.go) — Готовый middleware для `net/http`

## Плюсы
- Работает независимо от заголовков, User-Agent или репутации IP
- Никаких изменений на стороне клиента
- Ловит ботов, которые корректно подделывают все браузерные сигналы

## Минусы
- Нужно достаточно запросов с одного IP для надёжного паттерна (минимум ~5–10)
- Может задеть пользователей с медленным соединением или тяжёлыми расширениями
- Требует хранения состояния по IP (память или Redis)
