# ⏱️ Rate Limiting

> 🇬🇧 [Read in English](./README.md)

**Сложность:** ⭐⭐☆☆☆ | **Эффективность:** ⭐⭐⭐⭐☆

Ограничение количества запросов с одного IP за определённый период. Парсерам нужно делать много запросов быстро — rate limiting делает массовый парсинг медленным и дорогостоящим.

## Как работает

Каждому IP даётся бюджет запросов (например, 100 за 15 минут). При превышении лимита возвращается HTTP 429 Too Many Requests.

## Примеры

- [`nginx.conf`](./nginx.conf) — модуль `limit_req` в Nginx
- [`express.js`](./express.js) — Node.js с `express-rate-limit`
- [`fastapi.py`](./fastapi.py) — Python с `slowapi`

## Плюсы
- Легко внедрить
- Работает на уровне инфраструктуры (Nginx) — без кода в приложении
- Эффективен против простых парсеров

## Минусы
- Не останавливает распределённые парсеры (много IP)
- Может задеть реальных пользователей за общим NAT
- Для нескольких инстансов нужен Redis
