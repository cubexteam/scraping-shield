# 🎲 Рандомные CSS-классы

> 🇬🇧 [Read in English](./README.md)

**Сложность:** ⭐⭐⭐☆☆ | **Эффективность:** ⭐⭐⭐☆☆

Имена CSS-классов рандомизируются при каждой сборке. Парсер, нацеленный на `.price`, сломается после следующего деплоя.

## Примеры
- [`webpack.config.js`](./webpack.config.js) — CSS Modules с хэшированными именами классов
- [`component.jsx`](./component.jsx) — React-компонент на CSS Modules

## Плюсы
- Ломает парсеры, использующие CSS-селекторы
- Нулевые накладные расходы — обрабатывается на этапе сборки

## Минусы
- Не останавливает парсеры с визуальным/семантическим анализом
- Требует инструмента сборки (Webpack, Vite и др.)
