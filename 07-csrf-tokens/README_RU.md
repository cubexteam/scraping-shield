# 🔑 CSRF-токены

> 🇬🇧 [Read in English](./README.md)

**Сложность:** ⭐⭐⭐☆☆ | **Эффективность:** ⭐⭐⭐⭐⭐

Каждый API-запрос требует динамический одноразовый токен, который выдаётся только браузерной сессии. Парсер, не получивший токен предварительно, получит 403.

## Примеры
- [`server.js`](./server.js) — генерация и проверка токенов
- [`client.js`](./client.js) — получение токена перед каждым API-вызовом

## Плюсы
- Очень эффективно — токен нужно получить заранее отдельным запросом
- Токены одноразовые и с истечением срока

## Минусы
- Добавляет один дополнительный запрос на каждый API-вызов
- Нужно общее хранилище (Redis) для нескольких инстансов сервера
