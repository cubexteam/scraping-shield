# ⚡ JS-рендеринг данных

> 🇬🇧 [Read in English](./README.md)

**Сложность:** ⭐⭐⭐☆☆ | **Эффективность:** ⭐⭐⭐⭐☆

Загружать чувствительные данные (цены, контакты) через JavaScript после загрузки страницы. Простые HTTP-парсеры не выполняют JS и видят только заглушку.

## Примеры
- [`client.js`](./client.js) — подгрузка цен после загрузки страницы
- [`server.js`](./server.js) — API-эндпоинт с проверкой заголовков

## Плюсы
- Невидимо для парсеров на curl/requests
- Легко добавить поверх существующих страниц

## Минусы
- Headless-браузеры (Playwright, Puppeteer) выполняют JS и обходят это
- Требует клиентов с поддержкой JS (могут пострадать скринридеры)
