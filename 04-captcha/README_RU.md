# 🤖 Капча

> 🇬🇧 [Read in English](./README.md)

**Сложность:** ⭐⭐☆☆☆ | **Эффективность:** ⭐⭐⭐⭐☆

Показывать капчу подозрительным посетителям. Рекомендуется: **Cloudflare Turnstile** (невидимая, бесплатно) или **hCaptcha** (бесплатно).

## Примеры
- [`turnstile.html`](./turnstile.html) — виджет на фронтенде
- [`verify.js`](./verify.js) — проверка токена на сервере (Node.js)

## Плюсы
- Очень эффективна против автоматики
- Turnstile обычно невидима для реальных пользователей

## Минусы
- Добавляет трение для пользователей
- Существуют сервисы решения капч (2captcha и др.)
