# 🔍 Фильтрация User-Agent

> 🇬🇧 [Read in English](./README.md)

**Сложность:** ⭐⭐☆☆☆ | **Эффективность:** ⭐⭐⭐☆☆

Блокировка запросов от известных библиотек парсинга по заголовку `User-Agent`. Большинство простых парсеров не подделывают UA.

## Примеры
- [`nginx.conf`](./nginx.conf) — фильтрация по UA через map в Nginx
- [`express.js`](./express.js) — middleware для Express

## Плюсы
- Просто, без зависимостей
- Блокирует большую часть ленивых парсеров

## Минусы
- Тривиально обходится подменой UA-строки
- Не надёжен как единственный метод — используй в связке с другими
